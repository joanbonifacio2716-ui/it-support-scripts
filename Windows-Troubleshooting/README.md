# Windows Endpoint Troubleshooting Toolkit

A practical PowerShell project focused on common Windows endpoint and network troubleshooting tasks that can be encountered in an IT Service Desk or Tier 2 support environment.

The scripts in this folder are personal learning and portfolio projects designed to demonstrate troubleshooting logic, PowerShell fundamentals, system information gathering, and safe endpoint maintenance.

---

## Project Objectives

This project focuses on developing practical skills in:

* Windows endpoint troubleshooting
* System information gathering
* Network configuration checks
* Basic network connectivity diagnostics
* DNS troubleshooting
* Temporary file maintenance
* PowerShell scripting fundamentals
* Error handling and troubleshooting documentation

The goal is to create small, focused scripts that can support an initial troubleshooting workflow before escalating an issue to a higher-level resolver group.

---

## Environment

**Operating System**

* Windows 10 / Windows 11

**Tools & Technologies**

* PowerShell
* Windows PowerShell cmdlets
* Windows networking tools
* Windows Management Instrumentation / CIM
* TCP/IP
* DNS
* Basic endpoint troubleshooting
