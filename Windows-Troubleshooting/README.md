# Windows Troubleshooting PowerShell Scripts

This folder contains PowerShell scripts demonstrating common Windows workstation troubleshooting and maintenance tasks relevant to IT Service Desk and Tier 2 support.

## Scripts

### Get-SystemInfo.ps1
Collects basic workstation information such as:
- Computer name
- Windows version
- System architecture
- Manufacturer and model
- Processor
- Installed RAM
- IP configuration

### Get-IPConfiguration.ps1
Displays network adapter, IP address, default gateway, and DNS configuration.

### Test-NetworkConnectivity.ps1
Performs basic connectivity testing including:
- Internet connectivity
- DNS resolution
- HTTPS connectivity

### Clear-TempFiles.ps1
Removes temporary files from the current user's Windows Temp directory.

## Skills Demonstrated

- Network connectivity testing
- Windows maintenance
- IT Service Desk troubleshooting methodology

These scripts are intended for demonstration, learning, and authorized IT support or lab environments.

Always follow organizational policies and change-control procedures before running scripts on production systems.
