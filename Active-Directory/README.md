# Active Directory PowerShell Scripts

This folder contains PowerShell scripts designed to demonstrate common Active Directory administration and troubleshooting tasks performed in an IT Service Desk or Tier 2 support environment.

## Scripts

### Get-ADUserInfo.ps1
Retrieves common Active Directory user information, including:
- Display name
- Department
- Job title
- Email address
- Account status
- Lockout status
- Last logon information

### Unlock-ADAccount.ps1
Checks whether an Active Directory user account is locked and unlocks the account when required.

### Reset-ADPassword.ps1
Resets an Active Directory user's password and requires the user to change the temporary password at the next logon.

## Skills Demonstrated

- Active Directory user administration
- Account lockout troubleshooting
- Password reset workflow
- PowerShell scripting
- User account status verification
- IT Service Desk / Tier 2 troubleshooting

## Security Notice

These scripts are intended for demonstration, learning, and authorized IT administration or lab environments only.

Do not use them against production Active Directory environments without proper authorization and change-control procedures.
