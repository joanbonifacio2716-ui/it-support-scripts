# IT Support Scripts

A practical collection of PowerShell scripts designed to automate and troubleshoot common IT Service Desk, Help Desk, and Tier 2 support tasks in Windows environments.

## About

This repository demonstrates practical IT support and PowerShell automation skills, including:

* Active Directory user and account management
* Windows system information gathering
* Network connectivity troubleshooting
* DNS and TCP/IP diagnostics
* Temporary file cleanup
* Microsoft 365 support tasks
* Basic IT troubleshooting automation

The scripts are designed for use in controlled lab or enterprise support environments.

## Repository Structure

### Active Directory

Scripts related to common Active Directory support tasks.

* `Get-ADUserInfo.ps1` — Retrieves basic information about an AD user.
* `Unlock-ADAccount.ps1` — Unlocks a locked AD account.
* `Reset-ADPassword.ps1` — Resets an AD user's password.

### Windows Troubleshooting

Scripts for gathering system information and performing common workstation maintenance.

* `Get-SystemInfo.ps1`
* `Test-NetworkConnectivity.ps1`
* `Get-IPConfiguration.ps1`
* `Clear-TempFiles.ps1`

### Network Troubleshooting

Scripts for diagnosing common connectivity issues.

* `Test-DNS.ps1`
* `Test-TCPConnection.ps1`
* `Test-VPNConnectivity.ps1`

### Microsoft 365

Scripts and examples related to Microsoft 365 support and administration.
